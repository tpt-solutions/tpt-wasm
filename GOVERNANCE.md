# Governance

## Current model

TPT-Wasm is currently maintained by the project owner at TPT Solutions.

All architectural decisions are made by the project owner, documented in GitHub Issues,
and recorded in `docs/architecture/`.

## Decision process

1. Open a GitHub Issue with the `architecture` label.
2. Discussion happens in the issue.
3. The project owner records the decision in `docs/architecture/` and closes the issue.

## Milestones

Development proceeds through defined milestones (M0–M10) described in [todo.md](todo.md).
Each milestone has a definition of done in the project specification.

## Standards compliance

All implementation decisions are grounded in the normative WebAssembly specifications.
Deviations from the specification are bugs, not features.
